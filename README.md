# BlogsCorner

A personal blogging platform where developers can share articles on web development, JavaScript, React, and career growth.

## Features

- Role-based access for Admin, Author, and normal users
- Admin dashboard with blog management and statistics
- Author dashboard for creating, editing, and deleting blogs
- Comments from normal users
- Related blogs on blog detail pages
- Pagination for blog listings
- Responsive UI using Bootstrap

## Tech Stack

- React
- React Router
- Axios
- Bootstrap
- React Icons
- React Toastify
- json-server as a simulated REST API/database

## Getting Started

1. Clone the repository
2. Install dependencies
3. Start the application

```bash
npm install
npm start
```

## Project Structure

public folder has images and favicon
src folder contains all the source files
